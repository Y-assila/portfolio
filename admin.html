Portfolio admin

Sign in with a GitHub token. Only someone with write access to the repository can publish — the token never leaves your browser except to talk to GitHub.

How do I get a token?
  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  2. Repository access: Only select repositories → your portfolio repo.
  3. Permissions → Repository → Contents: Read and write (nothing else).
  4. Pick an expiry, generate, and paste it here.
